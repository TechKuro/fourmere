# Fourmere

Gate 3 supplier-credibility site for a UK specialist ecommerce venture.

## Current status
V2 design handoff is ready for implementation/refinement. The site is **not cleared for public deployment**.

## Current site shape
- static HTML + CSS;
- single-page supplier-credibility site;
- mailto-only contact;
- no catalogue, checkout, analytics, cookies or tracking;
- no production hosting/deployment authorised;
- current build remains `noindex,nofollow`.
